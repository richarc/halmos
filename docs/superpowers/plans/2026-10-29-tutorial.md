# Interactive Getting Started Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Help → Getting Started downloads (or takes from the app) a tutorial folder, opens its document, and the preview ticks each task as the user does it.

**Architecture:** Go `TutorialService` fetches and checks the portal's manifest and files (reusing `styleClient`'s GET), falls back to `docs/tutorial/` embedded in the binary, and writes a new folder. The frontend's `GettingStarted.svelte` dialog drives it; `lib/tutorialTasks.ts` is a markdown-it core rule that ticks marked task items.

**Tech Stack:** Go 1.25, `embed`, `net/http/httptest`; Svelte 5, TypeScript, markdown-it 14, vitest (jsdom).

**Spec:** `docs/superpowers/specs/2026-10-29-tutorial-design.md`

## Global Constraints

- Contract: `../hermesportal/docs/api/tutorial.md` (manifest `version` 1, `/tutorial/manifest.json`, file `url`s under `/tutorial/`).
- Names: `^[a-z0-9][a-z0-9-]*\.(md|bib|csv|tsv|json)$` or `^images/[a-z0-9][a-z0-9-]*\.(png|jpg)$`. Text ≤ 1 MiB, image ≤ 2 MiB, total < 16 MiB. `sha256` = 64 lowercase hex.
- Default folder `~/Documents/Halmos Tutorial`; next free `Halmos Tutorial 2`, `3`, …. Marker file `.halmos-tutorial.json` `{revision, source: "online"|"bundled", entry, created}`. Remembered folder in `<data>/hermes/tutorial.json` `{"folder": …}`.
- Bundled revision `bundled-<app version>` (`bundled-dev` when the version is empty).
- One 30 s deadline over the whole download.
- Copy (exact): "This is the tutorial that came with Halmos. An update brings the latest." / "New to Halmos? Help → Getting Started walks you through it." / "Could not write the tutorial: <reason>" / "Getting the tutorial…".
- Markers: `<!-- check: X -->` at the end of a task item, X ∈ `inline-math`, `display-math`, `chart`, `citation`, `table-caption`, `ref-fig`, `ref-tbl`, `ref-eq`. Done class `tutorial-task-done`.
- No new dependency. Colours from `style.css` variables only. Tests: `go test ./. && go build -o /dev/null .`; `cd frontend && npx vitest run < /dev/null`; `npx svelte-check`.

## Review Focus

- A manifest name with `..`, a leading `/`, a second folder level or an uppercase letter: refused before any request for files (Task 1 test `TestTutorialManifestRefusesBadNames`).
- The chosen folder exists and holds files (e.g. the user's earlier tutorial): nothing written, nothing replaced (Task 2 test `TestWriteTutorialRefusesNonEmptyFolder`).
- A task's result only in the finished example above the task list never ticks (Task 4 test "does not count the example above the task").
- Getting Started chosen with an unsaved document: the entry opens through the save/discard/cancel question, not over the edits (Task 5 test "opens the entry through the dirty guard").
- The download hangs: the bundled copy after the deadline, not a dialog stuck on "Getting the tutorial…" (Task 2 test `TestCreateTutorialDeadlineFallsBack`, with the deadline injected short).

### Task 2: TutorialService

**Files:**
- Create: `tutorialservice.go`, `tutorialservice_test.go`
- Modify: `main.go` (register the service)

**Interfaces:**
- Consumes: Task 1.
- Produces (bound to the frontend):
  - `type TutorialState struct { Existing string; ExistingEntry string; Suggested string }` (json `existing`, `existingEntry`, `suggested`)
  - `type TutorialResult struct { Entry string; Bundled bool; NeedsUpdate bool }` (json `entry`, `bundled`, `needsUpdate`)
  - `func (s *TutorialService) State() TutorialState` — `Suggested` = next free folder under `~/Documents` (`nextTutorialFolder(parent)`).
  - `func (s *TutorialService) ChooseLocation() (string, error)` — folder panel (`CanChooseDirectories(true)`, `CanChooseFiles(false)`, `CanCreateDirectories(true)`, title "Choose where to put the tutorial"); returns `nextTutorialFolder(chosen)`, `""` on cancel.
  - `func (s *TutorialService) Create(folder string) (TutorialResult, error)` — online content (or bundled on any `PortalError`, deadline, or `min_editor` newer than `appVersion()`; `NeedsUpdate` only in that last case), then `writeTutorial`, then remembers the folder. Returns the entry's absolute path.
- Internal: `func nextTutorialFolder(parent string) string`; `func writeTutorial(folder string, c *tutorialContent, now time.Time) error`; `newTutorialServiceWith(dataDir, docsDir string, client *styleClient, version string, deadline time.Duration)`.
