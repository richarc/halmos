# Pre-1.0 review: architecture, performance and security

Date: 2026-10-23
Scope: the whole editor at `944be50`: the Go backend (4,889 lines), the
Svelte/TypeScript frontend (9,966 lines), the Quick Look extension, build
and release.
Published: 2026-10-27, after v0.15.0 shipped the fixes. The full reports
were kept private until then, because S1–S2 described an unfixed way to
read a user's files.

Three reviews ran separately and read-only: architecture, performance and
security. Every number was measured on the reviewer's machine.

## Summary

Most of the app held up:

- Markdown, KaTeX, Mermaid, citations and links did not let a document run
  script.
- Tokens and document text were not logged.
- Recovery drafts were written with private permissions.
- The update check and the portal client pin where they connect to.
- Both test suites ran twice with no flakes, and the race detector was
  clean.

The serious problem was a chain of two findings. A chart in a document
could load data from any address (S1). One address it could load was the
app's own image route, which served any file on disk, not only images
(S2). Together, opening a document someone sent you could read a private
file and send it to another computer, with no script and no prompt. The
app set no Content-Security-Policy that would have stopped the request
going out (S3).

## Fixed in v0.15.0

| ID | Finding | Fix |
|---|---|---|
| S1 | Chart specs fetched any URL | Charts run with a loader that refuses every URL, and with Vega's expression interpreter; data must be inline (`charts.ts`) |
| S2 | `/_hermes/image` served any file | Image extensions only, symlink targets included, with a fixed `Content-Type`, `nosniff` and a `sandbox` CSP (`localImageFile`) |
| S3 | No Content-Security-Policy | The production app page has a CSP (`lib/csp.ts`); Quick Look keeps its offline rules and sandbox |
| S4 | Shipped advisories: DOMPurify (critical), markdown-it (high), KaTeX (low) | DOMPurify 3.4.17, markdown-it 14.3.3; KaTeX moves with Mermaid 12 in v0.16.0 |
| S5 | The export readers shared the image route's resolver | Fixed with S2, in the shared function |
| P1 | Reloading a large bibliography froze the editor (2.1–2.4 s at 2,000 entries) | Reload only when the content changes, parse in a Web Worker, keep the formatter for unchanged text; longest stall now 0.21–0.23 s |
| A2 (part) | The demo service could delete any path it was given | Its recording and full-screen methods refuse to run without `HERMES_DEMO` |
| A9 | CI did not run vet, the race detector or the Quick Look tests | Added |
| A10 | Stale notes in `CLAUDE.md` | Corrected |

## Deferred, with reasons

These are in the Backlog of `ROADMAP.md`.

| ID | Finding | Why it can wait |
|---|---|---|
| A2 (rest) | Go accepts any path the page sends | Matters only if script runs in the page, which S1–S3 guard against. Do it before AI features put model output in the page. |
| A3 | `App.svelte` is large, and its "a dialog is open" guard is copied 18 times | Works and is tested. Split it before more dialogs are added. |
| A4 | `DocumentService` has 37 methods over 9 concerns | A refactor, not a defect. |
| A5 | No diagnostics log | Becomes a support problem once there are paid services. |
| A6–A8 | Untyped events, unpinned Go/TS constants, facts mirrored across the boundary | Each is tested where it has caused a bug before. Pin the rest when touched. |
| A12 | No Windows or Linux build | A v1.2.0 item. |
| P2 | Editing a citation reformats all of them (186 ms at 200 citations) | Noticeable only on long, citation-heavy papers. citeproc's incremental update would fix it. |
| P3 | Each preview update re-parses all the rendered HTML (29 of 38 ms on 50 pages) | Fine at realistic sizes. |
| P4 | The startup bundle grew 25% (KaTeX bundled twice, the `.bib` parser loaded early) | Startup is still quick. |
| P5 | Render timing measures are never cleared | A few MB per hour of editing; a one-line fix. |
| S6 | Quick Look's offline rules are looser than needed | Its sandbox already blocks network access. |
| S7–S9 | Keychain item attributes; the portal address override and redirects; CSL DTDs on the preview path | Informational. No exploitable path found. |
